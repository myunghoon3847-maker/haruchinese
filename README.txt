하루중국어 100 v1.1 · 기초 문법 추가판

[가장 쉬운 실행 방법]
1. 압축을 풉니다.
2. index.html 파일을 Chrome 또는 Edge로 엽니다.
3. 단어, 문법, 플래시카드, 퀴즈 메뉴를 사용합니다.

[단일 파일판]
압축 파일과 별도로 제공되는 haru_chinese_100_grammar_v1_1.html은 파일 하나만 열어도 실행됩니다.

[주요 기능]
- 중국어 기초 단어 100개
- 기초 중국어 문법 20과
- 문법별 핵심 문형, 한국어 설명과 학습 팁
- 중국어 예문, 병음, 한국어식 발음, 한국어·영어 뜻
- 문법 예문 중국어 음성 재생
- 문법별 4지선다 연습문제와 학습 완료 기록
- 중국어 한자와 성조 포함 병음
- 한국어식 발음
- 한국어 뜻과 영어 뜻
- 중국어, 한국어, 영어 음성 읽기
- 검색과 주제 필터
- 오늘의 5단어와 오늘의 문법
- 즐겨찾기와 학습 완료 기록
- 플래시카드
- 10문제 4지선다 단어 퀴즈와 누적 정답률
- 스마트폰 반응형 UI
- PWA 설치 및 오프라인 캐시용 파일 포함

[음성 기능 안내]
음성은 브라우저의 Web Speech API와 기기에 설치된 TTS 음성을 사용합니다.
중국어 음성이 재생되지 않으면 운영체제의 언어/음성 설정에서 중국어 음성을 추가하거나 Chrome/Edge 최신 버전을 사용해 주세요.
한국어식 발음은 입문용 참고 표기이며 실제 중국어 발음과 완전히 같지는 않습니다.

[웹 배포]
폴더 안의 모든 파일을 GitHub Pages, Netlify 등 정적 웹 호스팅에 올리면 설치형 웹앱(PWA)으로 사용할 수 있습니다.
