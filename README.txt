하루중국어 100 v1.8 · Google 한국의(ko-KR) 음성판

[스마트폰에서 가장 간단하게 실행]
1. 함께 제공된 haru_chinese_mobile_v1_6.html 파일을 스마트폰에 저장합니다.
2. 파일 앱에서 해당 HTML 파일을 선택하고 Chrome으로 엽니다.
3. 회화 탭의 ‘자동 재생’을 누르면 실생활 회화 표현이 차례로 재생됩니다.

[홈 화면에 앱처럼 설치]
1. 이 폴더의 모든 파일을 GitHub Pages 또는 Netlify에 올립니다.
2. 스마트폰 Chrome에서 배포 주소를 엽니다.
3. 상단의 + 버튼 또는 Chrome 메뉴의 ‘앱 설치/홈 화면에 추가’를 누릅니다.
4. 홈 화면의 하루중국어 아이콘으로 실행합니다.

[v1.4 핵심 수정]
- 문법 예문 연속 재생 기능 제거
- 문법 20과 학습 기능은 그대로 유지
- 실생활 중국어 회화 표현 50개 자동 재생 추가
- 인사·소개, 언어·대화, 시간·일상, 길찾기·교통, 쇼핑·결제, 식당·카페, 여행·숙소, 도움·상황 분류
- 중국어만 / 중국어→한국어 / 중국어→한국어→영어 재생
- 속도 조절, 이전·다음, 일시정지·이어 듣기, 정지, 범위 반복, 현재 표현 반복

[전체 기능]
- 중국어 기초 단어 100개
- 실생활 중국어 회화 표현 50개 자동 재생
- 기초 중국어 문법 20과와 예문 40개
- 중국어·병음·한국어식 발음·한국어/영어 뜻
- 중국어/한국어/영어 음성
- 검색, 즐겨찾기, 완료 기록, 플래시카드, 4지선다 퀴즈

[음성 안내]
브라우저 정책상 처음에는 사용자가 자동 재생 버튼을 한 번 눌러야 합니다.
중국어 음성이 없으면 스마트폰 설정의 TTS 언어에서 중국어 음성을 추가해 주세요.
HTML 파일을 직접 열어도 학습 기능은 작동하지만, 홈 화면 설치와 오프라인 PWA 캐시는 HTTPS 웹 배포 환경에서 작동합니다.


[v1.5 아이콘 적용]
- 웹 브라우저 파비콘 적용
- Android/Chrome PWA 설치 아이콘 적용
- iPhone/iPad 홈 화면 아이콘 적용
- Windows 바탕화면/브라우저 바로가기 아이콘 적용
- 앱 상단과 메뉴 로고를 동일한 하루중국어 아이콘으로 통일


[v1.6 한국어 음성·재생 간격 개선]
- 한국어 TTS에서 자연형·여성형으로 알려진 음성을 우선 선택
- 기본 한국어 말투를 밝고 부드럽게 조정
- 귀엽게 / 밝고 부드럽게 / 자연스럽게 중 선택 가능
- 중국어 음성 종료 후 한국어 해석 전 기본 간격을 1.5초로 확대
- 0.9초 / 1.5초 / 2.2초 간격 선택 가능
- 선택한 한국어 음성 느낌과 간격을 기기에 저장

[주의]
웹앱은 기기에 설치된 TTS 음성을 사용하므로 실제 목소리는 스마트폰·브라우저마다 다릅니다. 지원되는 경우 자연형 또는 여성형 한국어 음성을 우선 사용하고, 그렇지 않으면 기기의 기본 한국어 음성을 사용합니다.


[v1.7 중국어·한국어 음색 통일]
- 중국어 TTS 음성을 기준 음성으로 선택
- 한국어 음성에서 같은 TTS 제조사·자연형 계열·성별을 우선 매칭
- 중국어와 한국어의 재생 속도·음높이·볼륨을 동일하게 적용
- 기존 귀엽게/부드럽게 음성 보정 제거
- 일치하는 다국어 음성이 없을 때는 기기의 가장 품질 높은 한국어 음성으로 자동 대체

[기술적 안내]
웹 브라우저 TTS는 언어별 음성 파일이 분리되어 있어 중국어와 한국어를 완전히 동일한 음성 파일로 재생할 수는 없습니다. v1.7은 기기에서 제공하는 음성 중 같은 제조사와 같은 계열을 찾아 음색 차이를 최소화합니다.


[v1.8 Google 한국의(ko-KR) 고정]
- 한국어 뜻 듣기와 회화 자동재생의 한국어 구간에서 Google 한국의(ko-KR) 음성을 최우선으로 선택합니다.
- 기기에 해당 Google 음성이 설치되지 않은 경우에만 사용 가능한 ko-KR 음성으로 자동 대체됩니다.
